# Changelog — RevOps Firefighter

- **v1** — Logic only, colored rectangles. Random non-overlapping reachable server placement, OK/BURNING/BURNED_DOWN state machine, escalating random ignition, burn-down timer, hold-SPACE-to-extinguish with progress bar, arrow-key movement with wall clamping, win/lose conditions, R to restart, debug text overlay.
- **v2** — Textured walls (border + 2 partition pillars) and 4 fixed desk obstacles the player collides with and servers avoid; main menu screen (Start/Exit wired up, Change Map + mute stubbed in disabled); brand palette + pixel-font stats HUD panel replacing the raw debug text; separate "X/3 SERVERS LOST" danger meter with a pulsing warning border; point system (+100 extinguish, -150 per server lost, +1/sec survived) with an in-memory top-5 session leaderboard shown on the end screen. All new textures (wall/floor/desk/HUD-frame/badge/menu-background) degrade to plain brand-colored shapes until the real PNGs are dropped into `/assets/images/`.
- **v3** — Server rack sprite (grayscale+darken filter for BURNED_DOWN) with an animated 8-frame fire overlay on BURNING servers; 4-direction player walk-cycle sprite (idle pose when not moving); looping muted autoplay background video on the main menu, falling back to the static wash image; Escape pause menu (Continue / Quit-to-menu) with a randomly-picked, non-repeating taunt line next to Quit. All new sprites/video degrade to the previous flat-shape rendering until dropped into `/assets/sprites/` and `/assets/video/`.
- **v3.1** — Map Select screen: "Start Game" now opens a 4-map picker (Open Floor/Easy, Cubicle Rows/Medium, Server Ring/Medium, Maze Grid/Hard) instead of starting straight into a run, each card showing a live schematic preview plus a difficulty badge and one-line description. The old disabled "Change Map" stub button on the main menu is removed — picking a layout is now just step two of starting any new game, including after Quit-to-menu. Under the hood, the fixed desk/partition layout moved out of `CONFIG` into a `MAPS` array, with `buildMapLayout()` computing the wall/desk/collision data for whichever map was picked.
- **v4** — `BURN_DOWN_TIME` doubled (8s -> 16s) so fires are less punishing to reach in time. Scoring simplified to a single rule: +1 per successful extinguish, no time bonus or burn-down penalty. New "Shantanu" boss event: once score reaches 10, a repeating 30s timer (frozen during pause) has him walk in from a random map edge on his own walk-cycle sprite, show a 2s speech bubble ("I have BAD SHANTANEWS for you!"), force-ignite one random OK server, then walk back out — modeled as its own `IDLE -> ENTERING -> TALKING -> WALKING_TO_TARGET -> IGNITING -> LEAVING` state machine that runs alongside normal gameplay (only his own movement pauses during the bubble). Skips the event cleanly if no OK servers are available, and only ever runs one instance at a time.
